# Project Statement

## Project Title

Library Management System

## 1. Problem Statement

Managing books and borrowing records manually can be difficult for a librarian. It can take time to find a particular book and keep track of which books are available or issued.

The purpose of this project is to develop a simple Python-based Library Management System that helps a librarian manage book records and issue/return transactions using CSV files.

## 2. Scope

The system covers the basic operations required to manage a small library. It allows the librarian to add, view, search, update and delete book records. It also allows books to be issued and returned and keeps a record of these transactions.

The project is mainly designed for use through the command line and is suitable for a small library.

## 3. Target Users

The main target user of this system is a librarian who needs to maintain book records and keep track of borrowing activities.

## 4. High-Level Features

The system provides the following main features:

* Add a new book
* View all books
* Search for a book
* Issue a book
* Return a book
* Update book details
* Delete a book
* View transaction history
* Generate a library report
* Validate common user inputs
* Store book and transaction data in CSV files

## 5. Expected Outcome

The project provides a simple way to manage library records digitally. It makes common library operations easier and keeps the book and transaction information organized.
